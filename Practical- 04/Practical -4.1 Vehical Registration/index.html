Anatomy of a plate

Four segments, read left to right

A valid registration number is exactly 10 characters, split into four fixed-length parts. RegoCheck checks each one in order and stops at the first rule that breaks.

01

State code

Characters 1–2. Two uppercase letters, e.g. MH.

02

District code

Characters 3–4. Two digits, e.g. 31.

03

Series

Characters 5–6. Two uppercase letters, e.g. AB.

04

Vehicle number

Characters 7–10. Four digits, e.g. 1234.
